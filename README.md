# Stardust Idea Tracker
## Description

Many of us have a wide variety of interests we'd like to explore, but busy schedules that are not accommodating of our curiosities. For example, someone may have an interest in creating clay figurines or learning about the history of mobile phones, but lack the time to truly look into these topics. Stardust was created to remind busy people of their curiosities and encourage them to pursue these interests.

Whether it be a topic to learn about, a hobby to pick up, or a recipe to try, Stardust helps you keeps track of your thoughts! Input any stream-of-consciousness words and assign a tag to it, and Stardust will keep your ideas organized. When you come back to the application later, you can reflect on past topics that you wanted to explore.

This application was created using React, JavaScript, CSS, and HTML with a JSON server database. It was completed under a 24-hour time constraint for the NwHacks 2025 cmd-f hackathon.

## Next Steps

In the future, we'd like to use AI to automatically tag each thought, rather than having the user directly tag them. Additionally, we'd like to provide the user with resources from the web that would help them further learn about their thoughts. Users would also be shown a past thought to remind them of an interest that they may have forgotten about.
